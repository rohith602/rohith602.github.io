Hummingbird ML-Agents: on-device vs. rented GPU training

Reward-curve comparison for a PPO agent trained on the Unity Learn "Hummingbird" mini project, showing the original on-device run (HB_01) against a later retrain on a rented GPU instance (HB_16) with a fixed observation gap (added velocity via stacked frames) and a 112-parallel-arena setup.

Bottom line: 10x the training steps in about 1/6th the active compute time — roughly a 60x per-step speedup. Most of that came from running 112 parallel simulation arenas across 28 rented vCPUs (Unity physics is CPU-bound); the GPU itself only contributed ~3.4% of the speedup, confirmed by a direct CPU-vs-CUDA benchmark on the same rented box.

Generated from each run's own TensorBoard event-file timestamps, not estimated. Part of the Hummingbird ML-Agents mini project.
