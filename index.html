Hummingbird — Reinforcement Learning Agent

2026 · Unity 6 · ML-Agents · PPO · Python

Trained a hummingbird agent to navigate a 3D environment and collect nectar using Proximal Policy Optimisation. Diagnosed an early reward plateau as an observation-space problem rather than a hyperparameter one, benchmarked parallel training layouts on a cloud GPU to find the fastest process split, and deployed the trained policy back into Unity as an ONNX model.
